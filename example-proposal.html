03

서비스 전략

중점 전략

"불확실성 감소"
진행 방식 명확화 + 시작점 단순화

Strategy Kernel

Where to play 신규 유저 중 구독 수업 조회자 (트래픽 44.7%)
How to win 불확실성 감소: 진행 방식 명확화 + 시작점 단순화
Coherent Bets 루틴형 결제완료율 개선, 일반형 신청시작률 개선, 첫회차 우선 노출
Trade-off 가격 할인 프로모션, 기존 유저 재구매, 원데이 개선 (Q2 검토)
Goals NSM: 구독 첫구매 +20% / Leading: 신청시작률, 결제완료율

주요 사용자

루틴형(1회) 구독 조회자

결제페이지 진입 후 이탈
  • 진행 방식/빈도가 불확실
  • 주 4-5회 빈도에 부담
  • 해지 방법을 모름

일반형(2회+) 구독 조회자

스케줄 확인 후 이탈
  • 중간 합류에 대한 불안
  • 커리큘럼 복잡성
  • 시작점이 불명확

유저 인사이트

검증된 인사이트 (유저 리서치):

  • 후기가 가장 중요한 고려사항 (33%, 1위)
  • 실현 가능한 커리큘럼 중시
  • 지인 소개가 가장 신뢰하는 정보 경로 (70%)

데이터 기반 추론 (가설, 정성 검증 필요):

  • 중간 합류 불안 - 일반형 신청시작률 27% 원인 추정
  • 결제 메커니즘 불안 - 루틴형 결제완료율 38% 원인 추정
  • 구독 = 장기 약속이라는 심리적 부담
04

기회리스트

1차는 바로 실행 (2주) / 2차는 1차 효과 검증 후 추가 실행

1차 Quick Win (2주 내 실행)

기회 해결 문제 상세 개발
결제페이지 진행 방식 안내 루틴형 결제완료율 38% 진행 예시, 빈도 부담 완화 메시지 3일
해지 용이성 안내 루틴형 결제완료율 38% "언제든 해지 가능" 명시 1일
첫회차 스케줄 우선 노출 일반형 신청시작률 27% 첫회차 상단 고정 + "새 시작" 배지 1주
중간 합류 안내 메시지 일반형 신청시작률 27% "지금 시작해도 괜찮아요" 안내 3일

2차 (효과 검증 후)

기회 해결 문제 상세 우선순위
소셜프루프 지표 노출 구독 전반 CVR 재수강률, 평균 수강 기간 표시 중간
수업 진행 미리보기 영상 구독 전반 CVR 30초 하이라이트 영상 중간
"첫 수업 시작하기" 프레이밍 장기 커밋 부담 버튼 문구 변경 중간

법무 필수 조치:

  • 자동결제 동의 체크박스 별도 추가
  • 결제 7일 전 자동 알림 시스템
  • 환불 정책 결제 페이지 표시
