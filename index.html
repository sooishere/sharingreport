3차 솔루션: 클로드 스킬 도입 (data-analysis)

각 단계를 클릭하면 상세 내용을 확인할 수 있습니다

데이터 요청
→
지식베이스 탐색
→
분석 계획 수립
→
계획 검증
→
승인
→
분석 실행
→
결과 검증
→
최종 결과

1. 요청 구분 (4가지 모드)

▼
ad-hoc, diagnostic, hypothesis, performance 중 자동 선택
ad-hoc - "파악해줘", "확인해줘", "얼마야"
→ 간단한 수치 확인, 즉시 결과 반환
diagnostic - "심층 분석", "왜", "원인"
→ 체계적 진단 리포트, 원인 분석
hypothesis - "검증해줘", "맞는지 확인"
→ 특정 가설 검증, 통계적 유의성
performance - "배포 결과", "성과 분석"
→ 배포/실험 성과 측정

2. 지식베이스 탐색

▼
5개 핵심 문서를 참조하여 정확한 데이터소스 선정
database_schema_reference.md
BigQuery 테이블, 필드, 관계 정의
amplitude-events.md
이벤트명, 프로퍼티, 수집 조건
metrics-definition.md
지표 정의, 계산식, 기준
tableau-dashboards.md
기존 대시보드, 기준 데이터
user-segments.md
유저 세그먼트 정의

3. 계획 검증 (4단계 자동 점검)

▼
사람에게 공유하기 전 4단계 자동 검증 수행
1
Knowledge Base 검증
테이블/필드 존재 여부 확인
2
Amplitude 검증
이벤트/프로퍼티 실제 존재 확인
3
Tableau 검증
기준선 참고 데이터 확보
4
data-analyst 검토
쿼리 로직, 필터 조건 검토

4. 분석 실행 (MCP 도구)

▼
3가지 데이터소스를 MCP로 직접 연결
BigQuery
execute_sql - SQL 쿼리 실행
get_table_info - 테이블 정보 조회
Amplitude
query_dataset - 데이터셋 조회
search - 이벤트 검색
Tableau
get-view-data - 뷰 데이터 조회
query-datasource - 소스 쿼리

5. 결과 검증

기준선 대비 ±5% 오차 확인 · 세부 합계=전체 정합성 · BigQuery vs Amplitude vs Tableau 교차 검증

솔루션: 클로드에게 워크플로우 구축 요청

탭을 클릭하면 프롬프트 전체 내용을 확인할 수 있습니다

클로드와 클로드 코드에서의 워크플로우를 구축하고 싶은데 어디서부터 시작해야할지 모르겠어. 워크플로우 구축에 필요한 클로드와 클로드 코드의 도구들을 제안해주고, 실제 워크플로우 구축까지 도움을 주면 좋겠어.
[현황] 1. 데이터분석 : 클로드 코드 또는 커서에 앰플리튜드, 빅쿼리 MCP를 연결해서 서비스 데이터 분석 1. 커서룰로 데이터 스키마, 이벤트 택소노미, 분석원칙을 만들어서 사용 중 2. 기획 초안으로 작성한 서비스 정책, 유저 스토리를 클로드 코드에서 넣어서 검토하고 보완해서 작성하는 워크플로우 실행 중 1. 이 단계에서는 특별한 원칙이나 룰을 따로 만들어두고 있진 않음 2. 유저스토리 기반으로 HTML 프로토타이핑 정도 하고 있음 3. 두개다 별도 폴더(프로젝트)로 진행 중
[원하는 방향] 1. 꾸그 서비스에 대한 전반적인 내용을 사전에 구성해놓고 서비스, 데이터 업데이트를 통해 지속적으로 내용을 업데이트 하고 싶음 2. 데이터 현황 분석을 통해 큰 서비스 제품 전략과 비즈니스 전략을 도출하고자 함 3. 비즈니스 전략, 제품 전략과 데이터 분석 내용, 인터뷰 및 고객 관찰 내용을 기반으로 기회 리스트를 뽑고자 함 1. 내가 창의적인 기회리스트 도출에 부족한 점이 많아서 아이디어를 창발하는데 도움받고 싶음 2. 필요한 경우 프로토타이핑을 여러개 만들면서 효과적인 기회리스트를 검토하고 싶음 4. 기회리스트와 데이터 분석내용을 기반으로 PRD를 작성하고 싶어. 1. 기존 데이터 분석 결과와 고객 관찰결과, 제품 전략을 기반으로 진행배경, 목표지표 설정 2. 기회리스트 내용 기반으로 서비스 정책, 유저스토리, 스펙리스트, 상세 요구사항 도출 5. 기회리스트를 배포하고 그 결과를 다시 데이터분석을 통해 분석 6. 클로드의 아티팩트나 클로드 코드의 서브에이전트, 스킬 같은 도구들을 적극적으로 활용하고 싶음 이런 워크플로우를 만들어서 진행한다고 할때 어디서부터 어디까지 세팅하고, 어떤 도구들을 사용해야할지 모르겟어. 더 확인하고 싶은 사항이 있다면 질문해줘
